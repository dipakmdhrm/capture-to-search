Capture to Search

Capture part of your screen and search it with Google Lens, from the Linux system tray. Source and releases.

APT repository

Installing the .deb registers this repository automatically, so later releases arrive through apt upgrade. To add it by hand: 

curl -fsSL https://dipakmdhrm.github.io/capture-to-search/key.gpg \
  | sudo tee /etc/apt/keyrings/capture-to-search.gpg > /dev/null

echo "deb [arch=amd64,arm64 signed-by=/etc/apt/keyrings/capture-to-search.gpg] \
https://dipakmdhrm.github.io/capture-to-search stable main" \
  | sudo tee /etc/apt/sources.list.d/capture-to-search.list

sudo apt update && sudo apt install capture-to-search

Other distributions

Fedora .rpm and Arch packages are attached to each GitHub release.
